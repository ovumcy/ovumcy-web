# Ovumcy Name and Logo

Ovumcy's code is licensed under AGPL v3 ([LICENSE](LICENSE)). That license covers copyright in
the code; it grants no right to the Ovumcy name or logo. This document says how they may be used.
It does not restrict anything the AGPL allows you to do with the code itself.

## Allowed without asking

- **Talking about Ovumcy.** Naming it to describe, review, compare, teach, or write about it.
- **Hosting or packaging an official release under its name**, including as a paid service, when
  all of the following hold:
  - what you install is an unmodified official release: an image from the official registry or a
    build of a tagged release. Changing only deployment configuration (environment, volumes,
    reverse proxy, base-image digest pinning) does not count as a modification;
  - the page offering it says, next to the name, that the offering is unofficial and not
    affiliated with or endorsed by the Ovumcy project;
  - the page links to the project's source repository,
    [github.com/ovumcy/ovumcy-web](https://github.com/ovumcy/ovumcy-web), where its users can get
    the source and report problems with Ovumcy itself;
  - the page names the release it installs, and new installs move to a newer release within 30
    days of that release being published;
  - the name describes what you host ("Ovumcy on Example Hosting") rather than naming your own
    product or company ("Official Ovumcy Hosting", "Ovumcy Pro").
- **Showing the logo unmodified** to identify the software, for example beside its name in an app
  catalog, following [web/static/brand/README.md](web/static/brand/README.md).

## Needs written permission

- Calling a modified version "Ovumcy". A fork takes its own name; it may say it is "based on
  Ovumcy".
- Using the name or logo in a product, company, or domain name, or in any way that suggests the
  project endorses, partners with, or operates your offering.
- Altering the logo, combining it with another mark, or using it as your own brand.

"Ovumcy Cloud" is the name of the project's own service and is not available to anyone else.
