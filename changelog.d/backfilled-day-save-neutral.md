### Fixed

- **Saving a past day no longer says it falls in your fertile window.** Filling in a day that is
  already behind you used to answer "this day is likely inside your estimated fertile window"
  whenever that date sat inside the window the current cycle projects. The estimate is about the
  days ahead, so that line now appears only when you save today (or a day still to come); a day
  you record after the fact gets the plain "Saved." message.
