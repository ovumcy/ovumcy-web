# Third-Party Licenses

Ovumcy is licensed under AGPL v3 (see [LICENSE](LICENSE)). This file lists the third-party
software redistributed as part of the built application — the Go modules statically linked into
the binary, the web assets embedded via `go:embed`, and the data files the runtime container
image ships — along with their licenses. The Go-module section is generated from the build
graph and verified in CI, so a dependency change cannot silently un-true the list.

## Go modules (statically linked into the binary)

Every third-party package below is compiled into the `ovumcy` binary that the release
artifacts and container images ship. The table is generated by `scripts/licensesdoc` from a
`go-licenses` report over the **shipped** binary's build graph (`GOOS=linux`, `CGO_ENABLED=0` —
the Dockerfile's build environment; the graph is GOOS-dependent, so a host-OS graph can differ
by a row) — the pinned tool version and the exact commands live in the
*Licenses inventory matches the dependency graph* step of `.github/workflows/ci.yml` and in the
script's usage header — and CI regenerates the report and refuses a stale committed block. Each
*license text* link points at the license file of the pinned module version (MIT, BSD-3-Clause
and Apache-2.0 notice obligations are met by this inventory together with the linked upstream
texts). A row is named by the deepest common ancestor of the packages sharing one license
file, so a row can name a subpackage (`golang.org/x/net/idna`) or appear beside its parent
(`…/brotli` and `…/brotli/flate`) when a repository carries more than one license.

## Tailwind CSS

- **Project:** [Tailwind CSS](https://tailwindcss.com) (`@tailwindcss/cli`, MIT licensed)
- **Files:** `web/static/css/tailwind.css` — compiled utility CSS produced by the Tailwind CLI
  from this project's templates, embedded via `go:embed` and served by the released binary and
  container images. The shipped file **is** redistributed, and its first line preserves
  Tailwind's own banner — `/*! tailwindcss <version> | MIT License | https://tailwindcss.com */`,
  with the version the pinned CLI emitted — which is the MIT notice for the utility declarations
  the compiler produced. That preserved banner, together with this entry, is the attribution; do
  not strip `/*! … */` comments from the bundle.

## Runtime container image

The `FROM scratch` runtime image copies these data artifacts out of an Alpine stage
(`Dockerfile` — `runtime-assets`):

- **Mozilla CA certificate bundle** (`/etc/ssl/certs/ca-certificates.crt`, from Alpine's
  `ca-certificates` package): the certificate data is from Mozilla's NSS `certdata.txt`,
  distributed under the [Mozilla Public License 2.0](https://www.mozilla.org/en-US/MPL/2.0/).
- **IANA Time Zone Database** (`/usr/share/zoneinfo`, from Alpine's `tzdata` package): the
  tz database is [public domain](https://www.iana.org/time-zones).
- **`/etc/passwd` and `/etc/group`**: two-line account databases for the unprivileged runtime
  user, written in the assets stage on top of the base files from Alpine's `alpine-baselayout`
  package (GPL-2.0-only). They are configuration data rather than program code, listed for the
  same completeness as the rest.

None of these is compiled into the binary; all ship in the container image and are listed here
for the completeness the scope sentence above promises.
